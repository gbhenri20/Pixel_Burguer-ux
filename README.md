# Pixel Burguer (web2)

App React + TypeScript + Vite do projeto Pixel Burguer.

Este diretório **não depende do Figma Make**. Para instruções completas (instalação, execução e estrutura), veja o [README na raiz do repositório](../README.md).

## Início rápido

```bash
npm install
npm run dev
```

Depois abra no navegador o endereço exibido no terminal (em geral `http://localhost:5173`).
