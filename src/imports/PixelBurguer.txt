Crie um site moderno, responsivo e interativo para uma lanchonete chamada **Pixel Burguer**, com uma identidade visual inspirada no universo dos **jogos eletrônicos, arcades e cultura gamer**, mas sem deixar o site infantil.

O objetivo é criar uma experiência de pedido de lanches online, com catálogo de produtos, carrinho, login opcional e navegação por diferentes páginas.

## 1. Identidade visual

Utilize um estilo moderno inspirado em videogames e fliperamas(Pixel Burguer):

* Tema gamer/arcade
* Fundo predominantemente escuro
* Elementos neon e efeitos de brilho
* Cards com bordas levemente arredondadas
* Animações suaves ao passar o mouse
* Ícones relacionados a jogos, controles, moedas, troféus e comida
* Tipografia moderna e fácil de ler
* Destaques visuais para promoções e produtos populares
* Evitar excesso de elementos para não prejudicar a usabilidade
* O site deve parecer profissional e adequado para uma lanchonete real

Crie uma identidade visual própria para a marca **Pixel Burguer**.

## 2. Estrutura de navegação

Criar uma barra de navegação fixa no topo contendo:

* Logo Pixel Burguer
* Início
* Cardápio
* Combos
* Promoções
* Sobre nós
* Contato
* Ícone do carrinho
* Botão "Entrar"

No mobile, transformar a navegação em um menu hambúrguer.

O carrinho deve mostrar visualmente a quantidade de produtos adicionados.

## 3. Tela inicial / Home

Criar uma página inicial impactante.

Hero section:

* Banner grande com uma imagem de hambúrguer
* Título como "Seu próximo nível de sabor"
* Texto curto apresentando a lanchonete
* Botão "Ver cardápio"
* Botão secundário "Montar meu pedido"

Adicionar uma seção de produtos em destaque.

Criar um **carrossel de produtos**, com navegação por setas e indicadores.

Exemplo:

* Pixel Burger
* Mega Bacon
* Chicken XP
* Batata Power
* Combo Gamer
* Milkshake Level Up

Cada produto deve possuir:

* Imagem
* Nome
* Descrição
* Preço
* Avaliação
* Botão "Adicionar ao carrinho"

Criar também uma seção de promoções com cards maiores.

## 4. Cardápio

Criar uma página exclusiva para o cardápio.

Adicionar categorias em abas:

* 🍔 Hambúrgueres
* 🍟 Porções
* 🌭 Lanches
* 🥤 Bebidas
* 🍰 Sobremesas
* 🎮 Combos

Ao selecionar uma categoria, exibir os produtos correspondentes.

Adicionar:

* Campo de pesquisa
* Filtro por categoria
* Ordenação por preço
* Ordenação por popularidade
* Cards de produtos

Cada card deve possuir um botão de adicionar ao carrinho.

Ao clicar no produto, abrir um modal ou página de detalhes contendo:

* Imagem grande
* Nome
* Descrição
* Ingredientes
* Preço
* Opções adicionais
* Quantidade
* Botão "Adicionar ao carrinho"

## 5. Carrinho

Criar uma página de carrinho moderna.

Exibir:

* Produtos adicionados
* Imagem do produto
* Nome
* Quantidade
* Botões + e -
* Preço individual
* Subtotal
* Taxa de entrega
* Desconto
* Total

Adicionar campo para cupom de desconto.

Botão principal:

"Continuar para pagamento"

Caso o carrinho esteja vazio, mostrar uma ilustração e uma mensagem:

"Seu inventário está vazio!"

Adicionar botão "Explorar cardápio".

## 6. Login opcional

Criar uma tela de login moderna.

Título:

"Entre para continuar sua jornada"

Campos:

* E-mail
* Senha

Botões:

* Entrar
* Criar conta
* Continuar como visitante

Adicionar opção "Esqueci minha senha".

O login deve ser opcional para realizar pedidos.

Criar também tela de cadastro com:

* Nome
* E-mail
* Telefone
* Senha
* Confirmar senha

## 7. Perfil do usuário

Depois do login, criar uma área "Minha conta".

Mostrar:

* Nome do usuário
* E-mail
* Dados pessoais
* Histórico de pedidos
* Pedidos favoritos
* Endereços cadastrados
* Configurações da conta
* Botão sair

Criar uma seção de histórico com status:

* Pedido recebido
* Em preparação
* Saiu para entrega
* Entregue

## 8. Checkout

Criar uma página de finalização de pedido.

Etapas:

1. Identificação
2. Endereço
3. Forma de pagamento
4. Revisão do pedido

Permitir:

* Entrega
* Retirada no estabelecimento

Para endereço:

* CEP
* Rua
* Número
* Complemento
* Bairro
* Cidade

Formas de pagamento:

* Cartão
* Pix
* Dinheiro

Não é necessário implementar pagamento real; criar apenas a interface funcional.

Antes de finalizar, mostrar um resumo completo do pedido.

Botão:

"Finalizar pedido"

Após finalizar, criar uma tela de confirmação:

"Pedido realizado com sucesso!"

Mostrar:

* Número do pedido
* Resumo
* Tempo estimado
* Status do pedido
* Botão "Acompanhar pedido"

## 19. Importante

O site deve parecer um **produto real**, e não apenas um protótipo simples.

Priorize:

* Boa hierarquia visual
* UX/UI profissional
* Acessibilidade
* Responsividade
* Código organizado
* Componentes reutilizáveis
* Estados de loading
* Estados vazios
* Feedback das ações
* Navegação intuitiva

Crie todas as páginas necessárias e conecte a navegação entre elas.

Não deixe botões sem função quando houver uma ação lógica possível.

Utilize imagens de alimentos visualmente atraentes e coerentes com o tema.

O resultado final deve transmitir a sensação de uma mistura entre **lanchonete moderna + arcade + videogame**, mantendo aparência profissional.
